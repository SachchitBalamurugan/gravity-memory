# Gravity Memory field notes

November 26, 2026. The first customer I would build for is the developer on call for a support or account agent. When a customer corrects a contact channel, that developer needs to know which value the agent can use today, who supplied it, and whether another process will see the same correction. A self-hosting team with restricted network access has a second job: keep collecting sources and investigating mistakes while inference is unavailable.

## What to keep from OpenCode

OpenCode discovers local models behind runtimes such as Ollama and LM Studio. Its hosted catalog also exposes models through a gateway. Seeing Gemini or Kimi in a menu establishes which provider can serve a request. Running offline additionally requires compatible weights, a runtime and sufficient hardware. Google's Gemma family supplies open weights. Moonshot's published Kimi K2 Instruct has roughly one trillion total parameters and 32 billion active per token. Those are material deployment differences for a laptop product. [OpenCode local discovery](https://github.com/anomalyco/opencode/blob/08cc1967e2bbf97e12381d25f9ae58cb5c74a51b/packages/core/src/plugin/provider/local.ts) · [OpenCode Zen](https://opencode.ai/docs/zen/) · [Gemini API](https://ai.google.dev/gemini-api/docs) · [Gemma](https://ai.google.dev/gemma/docs/core) · [Kimi model card](https://huggingface.co/moonshotai/Kimi-K2-Instruct)

**Keep the curated local model library.** An operator can inspect task, size, license and upstream card, install a hash-verified model, choose a preferred reviewer, and opt out of fallback. Review tries one model at a time and releases it before starting another. A timeout, local capacity error, missing installation or failed quote check can move the request to the next installed reviewer. A valid empty extraction is an abstention. Exhausted options leave the original available for manual review. Every attempt appears with its outcome. Search only uses vectors from the selected encoder's index. If that index or encoder is unavailable, full-text search can still return evidence. Explicitly configured Ollama models remain available through the CLI.

**Drop the trading marketplace and automatic cloud quota rotation.** There is no willingness-to-pay evidence for another list of models in these reports. Blind switching can change the meaning of a fact, mix incompatible embedding spaces, or send a private source off the device. A portable review setup has a concrete use: an operator can export weights and the verified Windows CPU runtime, import them on a disconnected workstation, and inspect the same source there. Model packs omit workspace records. Moving records is a separate export/restore decision. [Pinned catalog](gravity_memory/catalog.json) · [Local runtime](https://github.com/ggml-org/llama.cpp)

Ambiguous abbreviations and conditional clauses can go to review. Replayed the same messages with no gold keys supplied. |
| Enter an April source, record a June correction, then ask what was true in May. | The first version of the form assigned capture time to both. The browser journey failed at the historical answer. | Added a local effective-date input. The desktop journey now returns Dublin in May and Ghent after June. An archive search opens the cited passage with its original character span highlighted. | Review a source on a laptop with two small models. | The first actual model emitted a proposal that failed the evidence check. Turning it off left the source pending. | The router released the first process, tried the second installed model, showed both attempts, and returned a grounded value for a human to confirm. | Take an installed reviewer to an offline workstation. | A weights-only bundle left a clean Windows installation needing a separate runtime. | Added an optional runtime to the transfer. Imported SmolLM2 plus the pinned runtime into a fresh cache, then obtained a matching proposal from that cache. ## Commercial verdict

Ship this first to teams whose agents **act on changed information**. Measure minutes from a reported wrong value to the first correct, source-backed answer. Also measure time spent reviewing pending items, stale evidence exposed to callers, and cases where the operator cannot determine the correct subject. These costs determine whether this earns a place beside a team's existing database or Markdown files.

The most important unresolved product problem is conditional and multi-source memory. Two legitimate contact preferences can apply in different contexts. Even with a local embedding model, 62 of 120 test questions lacked a complete set of evidence in the first five. A pilot should replay anonymized corrections from real support workflows against Gravity Memory, the incumbent and the team's current workaround, with identical permissions, model budget, and blind review. This build establishes local behavior. It has no paid-pilot data or live three-product performance result.
